### 重要坑：Tauri v2 事件投递目标

`emit_to("popup", ...)` 走的是 `EventTarget::AnyLabel` 标签匹配（`tauri-2.10.2/src/manager/mod.rs` 的 `filter_target`），候选为 `EventTarget::Any` 时命中 `_ => false`。
而前端 `@tauri-apps/api` 的 `listen(event, handler)` 默认把 target 注册成 `{ kind: 'Any' }`（`node_modules/@tauri-apps/api/event.js:71-73`）。
→ **`emit_to(标签)` 无法被默认的 JS `listen()` 收到**；要用广播 `app.emit(...)`（`EventTarget::Any` 分支直接走无过滤的 `emit`）。本项目 `clipboard://updated` 也是广播。
`emit_to` 只有在前端显式 `listen(event, handler, { target: "popup" })` 时才可靠。

## 绿色版（免安装）打包方式

- 命令：`node node_modules/@tauri-apps/cli/tauri.js build --no-bundle`（会自动跑 `npm run build`）。
- `--no-bundle` 不产 MSI/NSIS，只出裸 exe，前端资源由 `tauri::generate_context!()` 在编译期内嵌，单文件即可运行。
- 产物：`src-tauri/target/release/paste_app.exe`；本地整理到 `release-portable/Xpaste.exe` + `Xpaste_v2.0.6_portable_win_x64.zip`。
- 耗时参考：release profile 开了 `lto=true` + `codegen-units=1` + `strip=true`，`cargo check` 约 8 分钟，完整 release 编译约 9 分钟（vite 33s + cargo 8m44s）。
- 运行依赖：Windows 需有 WebView2 Runtime（Win10 1803+ / Win11 通常已预装），绿色版无法像安装包那样自动引导安装。
- 数据位置（与标识符 `com.paste.app` 绑定，不随 exe 走）：
  - `%APPDATA%\com.paste.app\clipboard.db`（剪贴板数据）
  - `%APPDATA%\com.paste.app\clipboard.log`
  - `%APPDATA%\com.paste.app\hotkey.txt`（快捷键配置）
  - `%APPDATA%\com.paste.app\.first_run`（存在则不再自动开启开机自启）
- 注意：项目未接 `tauri-plugin-single-instance`，同时跑旧版 + 绿色版会两个进程操作同一个 db，测试前建议先退出旧实例。

### 环境坑（本机）

- Bash 工具在本机不可用（PortableGit 的 `bash.exe` 连 `ls`/`dirname` 都找不到），一律改用 PowerShell；且 PowerShell 的 stdout 不回显，需 `Set-Content` 落盘后再用 Read 读取。
