第一步

快速开始

三分钟从安装到第一次跨设备粘贴。

1

安装客户端

下载对应平台的安装包，或用 Homebrew 一行装完。

brew install xpaste

2

登录并配对

在第一台设备上登录，生成配对二维码；其他设备扫码即加入同一密钥空间。

3

开始使用

照常复制，在另一台设备按 ⌘V。历史面板用 ⌘⇧V 打开。

命令行

命令 说明
xp cp <file> --to <device>把标准输入或文件推送到指定设备
xp paste取出最近一条，写入 stdout
xp ls --type link列出历史，支持 --type 与 --device
xp status查看设备与同步状态

常见问题

免费版有限制吗？

核心同步、历史 500 条、全部平台都不收费。付费只影响历史保留时长与团队共享空间。

你们能看到我复制的内容吗？

不能。内容在本机加密后才上行，密钥不上传。代价是：忘记密钥就无法找回历史。

能在服务器上用它吗？

可以。CLI 支持无图形界面的 Linux，通过设备码登录，适合跳板机和 CI 环境。

支持自托管吗？

支持。同步端提供单文件二进制与 Docker 镜像，配置文件里指向自己的地址即可。
