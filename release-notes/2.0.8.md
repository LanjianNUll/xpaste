## 🎉 Xpaste v2.0.8

本版本给每套皮肤配上专属背景，并带来自动更新与无边框窗口。

### ✨ 皮肤与外观

- 十款皮肤各自配一张实景照片背景：春日花海、盛夏海湾、秋日林道、雪后森林、樱花、代码屏、紫调湖面、赤金落日、云雾远山、深蓝光束
- 新增「中国红」「中国风」「科技」三款皮肤，以及「光点上升」粒子动效
- 面板改为磨砂半透明，背景从界面后面透出来；浅色深色各有一套雾度与面板不透明度
- 新增「背景画法」开关：实景照片 / 简约渐变（不依赖图片资源的纯 CSS 风景）

### 🪟 窗口

- 主窗口去掉系统边框，标题栏区域融入皮肤背景，最小化 / 最大化 / 关闭改为自绘
- 快捷窗口同样去掉系统边框，并补上自绘关闭按钮

### 🔄 自动更新

- 启动时自动检查更新，发现新版本后自动下载，下载完成提示重启安装
- 更新包带签名校验，设置面板里也可以手动检查更新

### 🛠 发版流程

- 改版本号推送即自动构建 Windows 安装包与自动更新包，并生成更新日志发布 Release
