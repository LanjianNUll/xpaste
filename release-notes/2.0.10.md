### 🎨 界面改版

- 整体视觉改为 WorkBuddy 风格：统一圆角体系（4/6/10/14/18px），面板与控件不再使用生硬的直角
- 设置面板重做为「左侧图标导航 + 右侧内容卡片」，替换原来的顶部页签
- 外观设置按主题模式、皮肤、背景画法、背景动效拆成独立圆角卡片
- 皮肤卡片缩略图放大，支持自适应宫格排列，选中态改为描边加光环
- 快捷键改为停止输入 600ms 后自动生效，开机启动改为开关即时生效，无需再点保存

### 🍎 macOS 支持

- 合并 macOS 平台适配：剪贴板轮询、鼠标位置、⌘V 模拟粘贴、辅助功能权限探测
- 发版流程新增 macOS 构建，与 Windows 并行产出 dmg
- 签名自动两档判断：配置了 Apple 开发者证书则签名并公证，未配置则用 ad-hoc 签名出包

### 🐛 修复

- 修复 npm 与 Rust 两侧 Tauri 版本错位导致 CI 发版中断的问题
- Tauri 相关 crate 不再使用「2」通配，避免后续版本再次漂移
