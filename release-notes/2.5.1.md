### ✨ 新增功能

- **手动添加设备**：自动发现依赖 UDP 广播，跨网段、Wi-Fi 开了 AP 隔离、公司 VLAN 里可能一个包都收不到。现在可以填对方 IP 走纯 TCP 直连，这条路径不依赖广播；两台互相填上最稳。旁边会显示本机 IP，直接念给对方即可
- **网络诊断**：点一下逐项确认「TCP/UDP 端口有没有监听起来 → 房间有没有配上 → 每台邻居能不能握手」，把原来只显示「0 条」的情况拆成可判断的结论，并给出下一步（开本地网络权限 / 放行防火墙 / 手动填 IP）

### 🛠 修复与优化

- **两条通道的进度彻底分开**：原来中继和局域网共用一个发送水位，谁先成功谁把水位推走，另一条通道就再也发不出去。现在各记各的，任一通道通了内容就能到，重复投递由入库时的内容指纹自动去重
- **重新打开局域网不再补推历史**：开关重新打开时只补最近 7 天，不会把半年的内容一批批慢慢推过去
- **推送更耐抖动**：握手超时从 1.2 秒放宽到 4 秒，失败自动重试一次。拥挤的 Wi-Fi 上不再因为一次握手超时就丢掉一整批内容
- **失败原因带地址**：发送失败时状态里写清是哪台设备、什么原因，不再只有一句「发出 0 条」
- **只剩图片的一批也能推进进度**：整批都是「未开启同步的图片」时水位会正常前移，不再每 5 秒重复导出同一批
- 中继正常时也会顺手清空局域网收件箱，避免「对方说发了、这边没有」的悬空记录

### 🔧 工程与构建

- 邻居列表与诊断结果统一 camelCase 序列化，前端字段不再对不上
