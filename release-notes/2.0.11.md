### 🪟 窗口标题栏

- 标题栏改为按平台自绘：macOS 显示左上角红黄绿「红绿灯」，Windows 保留右上角最小化 / 最大化 / 关闭
- macOS 红绿灯悬停整组时才显出符号、窗口失焦整组变灰，贴近原生观感
- 关闭按钮统一为隐藏到托盘，与 Rust 侧拦截关闭的行为保持一致

### ⚙️ 设置面板

- 「通用」分组改为行式布局：每行「标题 + 说明 + 右侧控件」，不再层层套卡片
- 左栏导航固定，仅右侧内容独立滚动，滚动时导航不再被卷走
- 顶部主导航抽成配置项，后续加同级模块只需补一项与一个内容分支

### 🐛 修复

- macOS：快捷键只在按下时唤起快捷粘贴面板，长按或重复触发不再反复弹窗

### 🛠 发版流程

- 未配置 Apple 证书时不再向 tauri-bundler 传空签名变量，避免 macOS 构建中断
- 强制重发同一版本时原地更新 Release 的标题与说明
- 更新日志只保留分组条目，去掉冗余的版本与合并信息
