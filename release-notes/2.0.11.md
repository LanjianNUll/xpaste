### 🪟 窗口标题栏

- 标题栏改为按平台自绘：macOS 显示左上角红黄绿「红绿灯」，Windows 保留右上角最小化 / 最大化 / 关闭
- macOS 红绿灯悬停整组时才显出符号、窗口失焦整组变灰，贴近原生观感
- 关闭按钮统一为隐藏到托盘，与 Rust 侧拦截关闭的行为保持一致

### 🧭 主界面布局

- 改为左右结构：左侧固定侧边栏（剪贴板 / 历史管理 / 设置），右侧内容区
- 设置从弹窗改为右侧内容区的一个页面，不再层层套卡片
- 侧边栏底部预留用户登录位，功能上线前只占位
- 右侧标题栏与内容区共用同一层圆角边框，中间以发丝线分隔，观感连成一体
- 收紧内部圆角与间距，移除重复卡片样式

### 🖼 图片预览

- 新增全局图片预览：点击任意位置的图片缩略图即可全屏查看
- 支持滚轮缩放（以鼠标位置为锚点）、拖拽平移、旋转、下载原图、双击复位
- 键盘操作：`+` / `-` 缩放、方向键平移、`R` 旋转、`0` 复位、`Esc` 关闭
- 合并原先三处各自实现的预览逻辑，统一为一个组件

### 🎨 主题选择

- 「主题模式」与「皮肤」合并为一个「全部主题」网格
- 缩略图改为宽幅横向（16:9），名称在图下方居中，悬停轻微上浮
- 浅色 / 深色 / 跟随系统改用纯色块示意，跟随系统为左半浅右半深
- 色块上叠加示意界面元素，便于预判切换后的真实观感

### ⚙️ 设置面板

- 「通用」分组改为行式布局：每行「标题 + 说明 + 右侧控件」，不再层层套卡片
- 左栏导航固定，仅右侧内容独立滚动，滚动时导航不再被卷走
- 顶部主导航抽成配置项，后续加同级模块只需补一项与一个内容分支

### 🐛 修复

- macOS：快捷键只在按下时唤起快捷粘贴面板，长按或重复触发不再反复弹窗
- 皮肤背景下顶部导航文字对比度不足导致看不清的问题

### 🛠 发版流程

- 未配置 Apple 证书时不再向 tauri-bundler 传空签名变量，避免 macOS 构建中断
- 强制重发同一版本时原地更新 Release 的标题与说明
- 更新日志只保留分组条目，去掉冗余的版本与合并信息
