### 🌸 背景动效重做：每个主题一套纯 CSS 粒子

原来的粒子是 Canvas 2D 逐帧画的，一秒钟改几十次坐标。这次整体换成 **DOM + `@keyframes`**，运行期没有一行逐帧脚本——下落、摇摆、自转、翻转、闪烁全部交给合成器。

**每个主题不再是「一堆白点换个颜色」，而是各自的形态：**

| 主题 | 粒子 | 形态 |
| --- | --- | --- |
| 樱花 | 花瓣飘落 | 椭圆花瓣带一个略尖的角，自转之外还有整片 3D 翻面，翻过去时会收窄 |
| 冬雪 | 细雪 | 三档景深：远景小而实、近景大而糊，浅色下带冷蓝边和落影 |
| 春日 | 柳絮 | 极慢下沉、大幅横飘，绒球边缘带暖灰，像挂着光的白絮 |
| 秋叶 | 落叶 | 叶形带一条叶脉，五种暖色轮换，翻滚幅度比花瓣更大 |
| 盛夏 | 萤火虫 | 小光核 + 大光晕，椭圆游走与呼吸错开周期，明灭不同步 |

### 🔍 为了「看起来不假」做的几件事

- **每颗粒子三层**：垂直下落、水平摇摆、自身旋转分别挂在三个元素上，三种周期各不相同，轨迹才不会像一排东西同时掉下来
- **负延迟铺满屏幕**：粒子用随机的负 `animation-delay` 起步，页面一打开就是满屏飘落，不用等它从顶上一个个掉下来
- **浅色深色分别调色**：白色雪点在浅灰底上等于隐形，浅色模式改成「淡蓝灰球 + 白亮芯」；代码雨的荧光绿在白底上换成深绿；樱花在暗背景上整体提亮一档，但保留深粉边缘
- **尺寸随窗口走**：弹窗 360 宽时粒子缩到 0.8 并减少数量，主窗口恢复满密度，不会有「一颗花瓣占半屏」
- 系统开启「减少动态效果」时不播放粒子；窗口缩放的粒子重建做了防抖，拖窗口不会让动画不停从头开始
