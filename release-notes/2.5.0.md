### ✨ 新增功能

- **同步方向可控**：新增「双向 / 只发送 / 只接收」三档。只接收时本机内容不会传出去，只发送时不会把对方的内容写进本机；单向期间另一侧的进度不会被推进，切回双向会把攒下的内容补齐
- **条目标注来源设备**：同步过来的记录会显示来自哪台电脑（默认取系统主机名），快捷面板、历史列表、收藏列表都能看到；本机内容不显示来源
- **本机标识**：同步码下方显示本机名称，两台设备比对时能直接确认「这是同一台还是两台」

### 🛠 修复与优化

- **修复「显示连上却同步 0 条」**：传输端口改为独占绑定。此前允许两个实例同时监听 47832，旧版本还挂在菜单栏时，内核会把连接分给那个「不认识当前房间」的进程并静默拒绝。现在检测到端口被占用会直接提示「请退出旧版本」
- **修复把本机当成邻居**：同机多实例的广播会带上网卡地址，现在按网卡 IP 与回环地址过滤，不再出现「发现 1 台设备」而其实对端就是自己的情况
- **传输失败不再沉默**：发送被拒时把具体原因带进状态栏，不再只显示「发出 0 条」
- **区分「发现到」与「连得上」**：发现走 UDP 广播、传输走 TCP，两者独立。现在会真实探测对端端口，状态显示「已发现 X，但连不上：连接超时，多半是防火墙或网络隔离」
- 设备名从写死的「Mac / PC」升级为系统主机名，同平台的多台设备也能区分

### 🔧 工程与构建
